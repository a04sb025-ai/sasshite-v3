# ひかえめくん Riveアニメーション一覧 v1

## 1. 目的

この文書は、プレイヤーキャラクター「ひかえめくん」をRiveで実装する際の最小アニメーション構成を定義する。

目的:
- スマホ向けゲームで軽く、見やすく動かす
- 感情変化を小さく自然に伝える
- シーンごとに再利用できる基本動作を用意する
- PixiJS組み込み時に扱いやすい単位で管理する

## 2. アニメーション方針

- 大振りではなく小さく伝える
- ループ系と単発系を分ける
- 表情切替だけで済むものは無理に動かさない
- プレイヤーの観察や判断を邪魔しない

優先順位:
1. 待機
2. 視線変化
3. 気づき
4. 困り / 気まずさ
5. ほっとする
6. 手を伸ばす

## 3. 実装対象アニメーション

### A. 待機系

#### A-01 待機（立ち）
- 種別: ループ
- 用途: 基本状態
- 内容: わずかな上下動、呼吸感のある胴体の微動、ときどきまばたき
- 長さ目安: 2.0〜3.0秒
- 強さ: 弱

#### A-02 待機（座り）
- 種別: ループ
- 用途: 様子見・考え中
- 内容: 少し体を揺らす、ときどきまばたき、肩や頭がわずかに沈む
- 長さ目安: 2.0〜3.0秒
- 強さ: 弱

#### A-03 まばたき
- 種別: 単発 / ループ内利用
- 用途: 待機や会話中に挿入
- 長さ目安: 0.15〜0.25秒

### B. 視線・認知系

#### B-01 きょろきょろ
- 種別: 短ループ / 単発
- 用途: 周囲の様子をうかがう
- 内容: 顔または視線を左右へ小さく動かす
- 長さ目安: 1.2〜1.8秒

#### B-02 気づく
- 種別: 単発
- 用途: 違和感やヒントに気づく瞬間
- 内容: 目を少し開く、顔を少し上げる、必要なら小さな反応記号
- 長さ目安: 0.4〜0.8秒

#### B-03 考える
- 種別: 短ループ
- 用途: 判断待ち
- 内容: 目線が少し泳ぐ、首または顔が少し傾く
- 長さ目安: 1.5〜2.0秒

### C. 困り・迷い系

#### C-01 ちょっと気まずい
- 種別: 単発 → 静止
- 用途: 空気を読み違えそうなとき
- 内容: 眉がやや下がる、口が小さく変化、必要なら控えめな汗マーク
- 長さ目安: 0.4〜0.8秒

#### C-02 ためらい
- 種別: 短ループ
- 用途: 行動するか迷う
- 内容: 少し身を引く、片手や肩がわずかに止まる
- 長さ目安: 1.0〜1.6秒

#### C-03 あわあわ / 焦り
- 種別: 単発または短ループ
- 用途: 間違えそう、急ぎたい
- 内容: 顔がわずかに揺れる、眉や口が焦り表現に変化
- 長さ目安: 0.8〜1.2秒

### D. 安心・成功系

#### D-01 ほっとする
- 種別: 単発
- 用途: 良い判断のあと
- 内容: 肩の力が抜ける、目や口がやさしくゆるむ、小さく息を吐く印象
- 長さ目安: 0.6〜1.0秒

#### D-02 うれしい
- 種別: 単発
- 用途: 成功や共感の成立
- 内容: 控えめな笑顔、体が少し上向く
- 長さ目安: 0.5〜0.9秒

#### D-03 決意
- 種別: 単発
- 用途: 行動を選ぶ直前
- 内容: 目線が定まる、姿勢が少し前向きになる
- 長さ目安: 0.4〜0.8秒

### E. アクション系

#### E-01 手をのばす
- 種別: 単発
- 用途: 何かに働きかける
- 内容: 片手を前方へ伸ばす、体重が少し移動する
- 長さ目安: 0.5〜0.9秒

#### E-02 小さく身を引く
- 種別: 単発
- 用途: とまどい、遠慮
- 内容: 上体を少し後ろへ、顔もわずかに引く
- 長さ目安: 0.4〜0.8秒

#### E-03 一歩ふみ出す
- 種別: 単発
- 用途: 行動開始
- 内容: 小さく前へ出る。大きな歩行ではなく「決めた」感を優先
- 長さ目安: 0.5〜0.9秒

## 4. PoC最小実装セット

必須:
- A-01 待機（立ち）
- A-02 待機（座り）
- A-03 まばたき
- B-02 気づく
- C-01 ちょっと気まずい
- C-02 ためらい
- D-01 ほっとする
- E-01 手をのばす

余裕があれば追加:
- B-01 きょろきょろ
- C-03 あわあわ
- D-03 決意
- E-03 一歩ふみ出す

## 5. Rive実装メモ

推奨:
- State Machineはまず1本
- 入力はBool / Trigger / Numberを最小限にする

想定入力例:
- `isSitting`
- `isThinking`
- `noticed`
- `awkward`
- `relieved`
- `reachOut`
- `determined`

実装方針:
- 待機はループ
- 気づき / ほっとする / 手をのばす はTrigger
- 座り / 立ちはBool切替
- 感情の重ねがけはPoCでは避ける

## 6. PixiJS側の利用イメージ

- 通常時 → 待機（立ち）
- 観察中 → 考える / きょろきょろ
- 違和感検知 → 気づく
- 迷い中 → ためらい
- ミス寄り → ちょっと気まずい / あわあわ
- 良い状態 → ほっとする / うれしい
- 行動入力 → 手をのばす / 一歩ふみ出す

## 8. 重要な設計原則

ひかえめくんのアニメーションは、プレイヤーより先に答えを示してはいけない。

「察して。」の判断主体はプレイヤーであり、主人公の表情や動きは操作・観察・結果を補助するために使う。
