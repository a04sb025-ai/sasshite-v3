# ひかえめくん キャラクター仕様 v0.1

## 1. 役割

「察して。」のプレイヤーが感情移入するための主人公ポジション。

メインキャラクターではあるが、強い人格を押し出すヒーローではない。

役割は、

- 周囲の空気を見る
- 違和感に気づく
- 少し迷う
- 小さく行動する
- 行動の結果で場が変わる

というゲーム体験を、プレイヤーに自然につなぐこと。

## 2. コアコンセプト

**出しゃばらないけど、ちゃんと気づける人。**

### 印象キーワード

- やさしい
- ひかえめ
- 観察している
- 少し不器用
- 親しみやすい
- 完璧ではない
- 応援したくなる

## 3. 名前

仮称：**ひかえめくん**

現段階では制作上の呼称。正式名称は後から変更可能。

## 4. 年齢・性別感

- 年齢を限定しすぎない
- 若い人にも学生にも見える程度
- 性別を強く限定しない中性的寄り
- 学校、電車、公共空間、職場など幅広い場面に馴染むこと

## 5. 頭身

**2.6〜2.8頭身。基準は約2.7頭身。**

目的：

- スマホでも姿勢・視線・感情が読みやすい
- 親しみやすい
- Riveで動かしやすい
- リアルすぎず記号的すぎない

## 6. シルエット

- 頭は大きめ
- 肩幅は狭め
- 手足は簡潔
- 全体として角より丸
- 一目で主人公と分かるが、派手すぎない

## 7. 顔

### 目
- 小さめの黒目中心
- 白目を強調しない
- 細かい描き込みはしない

### 眉
- 感情表現の主要パーツ
- 小さな角度差で「気づく」「迷う」「困る」「安心」を出す

### 口
- 短い線〜小さな開口
- 大げさにしない

### 頬
- 通常はなし
- 緊張・照れ・気まずさの時だけ薄く使うことは可能

## 8. 髪

- 少し丸みのある短髪
- 前髪に軽い特徴
- 少しだけ左右非対称
- 毛束やレイヤーを増やしすぎない
- Riveで前髪・後ろ髪を分けやすい形

避ける：

- 極端なツンツン髪
- 長髪
- 複雑な毛束
- 強いアニメ記号

## 9. 服装

基本：

- 無地のシンプルなトップス
- ロングパンツ
- シンプルな靴
- ロゴや柄は原則なし

制服・スーツ・特定職業の服に見えすぎないこと。

## 10. 配色

主人公アクセント：**淡い水色〜青系**

- メイン：やわらかい水色
- 補助：少し落ち着いた青
- 線：濃いグレー〜黒

目的は「主人公が分かること」であり、派手に目立たせることではない。

NPCは原則グレー基調とする。

## 11. 性格

### 長所
- 違和感に気づこうとする
- 相手の立場を考える
- 小さくても行動できる

### 弱さ
- すぐに動けないことがある
- 考えすぎる
- 自信満々ではない

完璧超人にはしない。

## 12. 必須表情

1. Neutral / 通常
2. Notice / 気づく
3. Concern / 困る
4. Awkward / 気まずい
5. Flustered / あわてる
6. Focus / 行動する
7. Relief / ほっとする

表情は大げさな顔芸ではなく、眉・目・口・顔の角度の小さな差で表現する。

## 13. 必須ポーズ

- 立ち正面
- 立ち斜め
- 座り
- 歩き
- 手を伸ばす
- 少し引く
- 迷う
- ほっとする

## 14. アニメーション方針

常時アニメーション：

- ごく小さい呼吸
- 自然なまばたき
- 微小な重心移動
- ときどきの視線移動

反応アニメーション：

- 注視
- 迷い
- 手を伸ばす
- 身体を少し引く
- 安堵

止まっているようで完全には止まっていない状態を作る。

## 16. NPCとの差別化

主人公：
- 淡い水色
- 表情・目線を少し丁寧に見せる

NPC：
- グレー基調
- 主人公より情報量を少し減らす
- 属性は髪型・服・小物・体型で最小限に表現

主人公だけ別作品のように豪華にしない。

## 17. 禁止事項

- ヒーロー感を強くする
- 萌え・美少女・イケメン方向へ寄せる
- ギャグ顔を常用する
- 描き込みを増やしすぎる
- 主人公自身がプレイヤーより先に正解へ気づく演技をする
- NPCの反応を見る前に主人公の表情で答えを教える

## 18. 一言定義

**静かに気づいて、そっと動ける主人公。**
